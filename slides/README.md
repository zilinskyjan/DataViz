# Slides and Presentations

This folder contains RevealJS slide presentations (not part of the main book).

## Contents

- **`r-snippets-teaching.qmd`** - Practical R code snippets for data visualization and analysis
- **`ajps-reanalysis-dataviz.qmd`** - ggplot practice with American politics data
- **`intro-ai-teaching.qmd`** - AI as a teaching tool (opportunities and risks)
- **`nationscale-dataviz.qmd`** - ggplot lesson using Nationscape surveys
- **`intro-ai-teaching.css`** - Custom CSS styles for slide presentations

## Rendering Slides

To render any of these slide presentations:

```bash
quarto render slides/filename.qmd
```

The output will be an HTML file that can be opened in a browser or presented using RevealJS.
